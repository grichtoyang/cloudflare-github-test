# 每日盤前分析 V1.0 — Markdown 報告模板

> **文件狀態：V1.0 擴充定案候選版**  
> 本次直接覆寫既有 `docs/REPORT_TEMPLATE.md`；不升版、不另建 V1.1。

## 0. 執行與資料品質規則

1. 報告必須完成五大分析區塊：台股現貨、總體與海外市場、台指期、選擇權、綜合結論。
2. 任何資料不可取得、格式錯誤、逾時或來源不一致時，必須記錄於「資料品質與錯誤紀錄」，不可默認為 0、不可自行補值。
3. 必須先完成資料品質檢查，再進行方向判讀；若關鍵資料缺失，結論須標示「受限」。
4. 每一項結論都要區分：官方數據、計算結果、技術推論、情境假設。
5. 所有圖表必須同時揭露圖表用途、資料來源、計算期間、欄位與缺值狀態。
6. 報告即使中途發生錯誤，也必須完成輸出 Markdown 報告後才可停止；錯誤需寫入錯誤紀錄。
7. 時間以台灣時間 Asia/Taipei 表示；資料日期與交易時段必須明確標示。
