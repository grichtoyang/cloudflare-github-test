# 每日盤前分析 V1.0 — 報告模板

> 固定輸出順序：現貨、重要市場、期貨、選擇權、綜合總結。所有重要原始數據、關鍵位、圖表資料與資料限制均須揭示。

## 0. 共通規則

- 明確標示報告日期、資料截止時間、時區、來源、單位。
- 缺值、延遲、估算、未公布資料必須明確標註。
- 前四模組提供資料與分析；第五模組只整合，不重新抓取或重複製造資料。
- 結論使用：偏多、偏空、中性、震盪、資料不足、方向未確認。
- 分析條件不等於交易訊號；不得把推論寫成確定性預測。

# 一、現貨分析模組

## 1.1 大盤行情

| 項目 | 必揭示資訊 |
|---|---|
| 加權指數 | 開、高、低、收、漲跌點、漲跌幅 |
| 成交量 | 股數、成交金額、與前一日比較 |
| 市場廣度 | 上漲、下跌、平盤、漲停、跌停家數 |
| 日線結構 | 紅黑K、實體、上下影線、缺口 |
| 均線 | MA5、MA10、MA20、MA60 |
| 波動 | ATR、振幅、近5／20日波動 |
| 關鍵位 | 前高、前低、缺口、支撐、壓力 |

必答：趨勢或盤整？量價是否配合？價格與均線是否一致？重要支撐壓力在哪裡？

## 1.2 現貨籌碼

- 三大法人：外資、投信、自營商買賣超金額、連續日數、累積趨勢。
- 融資餘額、融券餘額、融資維持率。
- 借券餘額、借券賣出量／金額。
- 法人籌碼與指數漲跌是否同向、背離、反轉或異常。

## 1.3 類股與產業

- 電子、金融、半導體、AI、PCB、重要權值股與強弱產業。
- 判斷指數是否由少數權值股推動，以及產業強弱對隔日的影響。

## 1.4 現貨結論

- 方向、主要支撐／壓力、法人是否支持、對台指期的影響。

# 二、重要市場分析模組

## 2.1 美股

NASDAQ、S&P 500、道瓊、SOX、VIX：收盤、漲跌點、漲跌幅、趨勢及風險意義。說明科技股／半導體是否與台股電子權值股同向。

## 2.2 利率與匯率

- 美債2Y、10Y、20Y、30Y殖利率及日變化。
- 殖利率曲線、利率上升／下降對科技股的影響。
- DXY、USD/TWD、USD/JPY及台幣升貶方向。

## 2.3 亞洲市場

日經、韓股及重要亞洲指數的收盤、漲跌與是否和美股同向。

## 2.4 產業與重大新聞

AI、半導體、HBM、先進封裝、PCB、CPO、Fed、通膨、就業、利率、地緣政治及重大經濟事件。每則新聞揭示：事件、方向、影響對象、可能影響、可信度。

## 2.5 重要市場結論

外部市場方向、對台股開盤的可能影響、隔日需注意的事件與國際風險。

# 三、期貨分析模組

## 3.1 日盤期貨行情

- 近月台指期：開、高、低、收、漲跌點、漲跌幅、成交量。
- 期現貨價差、基差、正逆價差。
- 期貨與現貨方向是否一致。
- 前高、前低、缺口、主要支撐壓力與結構。

## 3.2 每日日盤後法人未平倉

| 法人 | 多方未平倉 | 空方未平倉 | 淨部位 | 與前一日變化 |
|---|---:|---:|---:|---:|
| 外資 |  |  |  |  |
| 投信 |  |  |  |  |
| 自營商 |  |  |  |  |
| 三大法人合計 |  |  |  |  |

外資淨部位為核心，投信與自營商輔助確認；判斷增多、增空、回補、減碼或翻轉。

## 3.3 夜盤分析（精簡但必要）

### A. 每日日盤後法人未平倉

揭示日盤結束後公布的三大法人期貨未平倉，並與前一交易日比較，作為夜盤前法人基準部位。

### B. 夜盤交易期間法人即時增減部位

- 優先取得夜盤期間外資、投信、自營商期貨部位的即時或分時變化。
- 必須確認資料來源是否真的提供「夜盤期間法人部位變化」。
- 若官方只公布夜盤交易口數／金額，不能把交易口數直接寫成即時淨部位。
- 必須標示：已取得、僅有交易量／金額、尚未公布、無可靠來源。

### C. 夜盤價格與成交量

夜盤開盤、目前／收盤、漲跌點、漲跌幅、成交量，以及與日盤收盤的比較。

### 夜盤核心判讀

1. 法人增加多單、增加空單、減碼或回補？
2. 夜盤價格漲跌與法人變化是否一致？
3. 價漲法人偏空、價跌法人回補等情況標示為背離與隔日風險。
4. 夜盤只能推估隔日日盤方向與風險，不是確定開盤預測。

## 3.4 期貨結論

日盤法人方向、夜盤新增佈局及資料可信度、夜盤價格／成交量與法人一致性、期現貨背離、隔日日盤方向與風險。

# 四、選擇權分析模組

## 4.1 資料範圍

近月與當週分開分析；標示到期月份、履約價、Call／Put、OI、成交量、成交金額及法人資料。選擇權OI以日盤結束後公布資料為準，不虛構夜盤獨立OI。

## 4.2 原始資料

Call／Put OI、成交量、成交金額；外資與自營商交易口數／金額；主要履約價集中區；Call／Put買賣方向；日盤與夜盤量價變化。

## 4.3 夜盤選擇權部位

- 揭示外資與自營商夜盤 Buy Call、Sell Call、Buy Put、Sell Put 的交易金額變化。
- 特別檢查外資 Buy Put 避險金額是否異常暴增。
- 揭示前一日、當日、變化金額、變化幅度、占比及異常狀態。
- 夜盤交易金額不等於新增OI；無法確認開倉／平倉時，不得直接解讀為新增部位。
- 觀察選擇權夜盤方向與期貨夜盤方向是否一致。

## 4.4 關鍵位與衍生指標

Call Wall、Put Wall、Gamma Wall、Gamma Flip、Max Pain、GEX、Delta、Call／Put OI集中區；比較前一日／前次結算的上移、下移、增強、減弱，並揭示與台指期現價的距離。

## 4.5 選擇權結論

多空籌碼、支撐壓力、Gamma環境、外資／自營商夜盤避險異常，以及對台指期的磁吸、支撐、壓力或加速風險。

## 5.2 最終必答六題

1. 今日台股開盤前整體方向是什麼？
2. 台指期偏多、偏空還是震盪？
3. 重要支撐與壓力在哪裡？
4. 哪些因素支持判斷？
5. 哪些因素可能推翻判斷？
6. 今日有哪些交易風險需要避免？

## 5.3 情境推演

- 情境A偏多：觸發條件、確認訊號、上方目標、失效條件。
- 情境B偏空：觸發條件、確認訊號、下方目標、失效條件。
- 情境C震盪／不交易：區間、雙邊關鍵位、避免追價條件。

## 5.4 最終結論

- 市場狀態：趨勢／區間／轉換／資料不足。
- 開盤方向：偏多／偏空／中性／震盪。
- 台指期偏向：多方／空方／等待確認。
- 主要支撐：S1、S2、S3。
- 主要壓力：R1、R2、R3。
- 最重要觀察：最多三項。
- 可能推翻判斷的訊號：最多三項。
- 風險提醒與交易原則：價格行為未確認前不追價、不交易。

# 六、重要圖表與數據揭示清單

至少揭示：

1. 加權指數日線／成交量圖。
2. 三大法人現貨買賣超與累積趨勢。
3. NASDAQ、S&P 500、SOX漲跌比較。
4. 美債殖利率、DXY、USD/TWD變化。
5. 台指期價格、成交量、期現貨基差。
6. 期貨三大法人淨部位與前一日變化。
7. 夜盤價格漲跌與成交量。
8. 夜盤法人交易／部位變化；無可靠資料時顯示未公布／不可推定。
9. 選擇權Call／Put OI與成交量分布。

11. 外資／自營商Buy Call、Sell Call、Buy Put、Sell Put金額變化。
12. 五大模組方向一致性矩陣。

每張圖表附資料日期、來源、單位、解讀及限制；原始數據不可被圖表完全取代。

# 七、資料品質與完成檢查

- 每模組列出實際來源，區分官方、代理、替代與推估資料。
- TAIFEX若無夜盤法人即時部位公開資料，必須明確揭示，不得以成交口數／金額冒充淨部位。
- 選擇權若無夜盤獨立OI，使用日盤結束後OI；夜盤只分析交易口數／金額。
- 發生錯誤仍須完成報告，並列出資料缺口及其影響。
