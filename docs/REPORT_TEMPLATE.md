## 0. 執行與資料品質規則

1. 執行後不得因單一 API、資料源或分析模組錯誤而提前停止。
2. 即使部分資料取得失敗，仍必須完成 Markdown 報告，並標註 `Unavailable`、`Fallback` 或 `Partial`。
3. 不得捏造數據；所有數值必須附資料日期、資料來源與必要的計算說明。
4. 報告最後必須列出成功項目、失敗項目、Fallback 狀態與整體完成度。
5. 第五模組只負責整合前四模組結果，不重新抓取相同資料。

## 3.3 夜盤分析：夜盤法人佈局核心

> 夜盤分析只保留三項必要資訊：**日盤後法人未平倉、夜盤期間法人交易部位變化、夜盤價格與成交量**。不得擴充成另一套完整技術分析模組。

### A. 每日日盤後法人未平倉

以日盤收盤後公布的三大法人期貨未平倉作為夜盤法人佈局的基準值：

- 外資及陸資淨未平倉
- 投信淨未平倉
- 自營商淨未平倉
- 三大法人合計淨未平倉
- 與前一交易日比較的增減

### B. 夜盤交易期間法人部位變化

必須確認並揭露資料能力：

- TAIFEX 公開夜盤法人資料目前可提供**夜盤交易量、交易金額及多空淨交易量**。
- TAIFEX 公開資料並非盤中逐筆或即時公布法人未平倉，因此不能把夜盤交易淨量直接宣稱為即時 OI。
- 若資料源只提供夜盤法人交易量／交易金額，報告欄位應命名為：**夜盤法人交易部位變化／夜盤多空交易淨量**，不可誤寫成「即時未平倉」。
- 若未來取得券商、交易所授權或其他可驗證的盤中法人 OI 資料，才可增加「夜盤即時未平倉變化」。

| 法人 | 夜盤多單交易量 | 夜盤空單交易量 | 夜盤多空淨交易量 | 相對日盤後基準 | 可否推估部位方向 |
|---|---:|---:|---:|---:|---|
| 外資及陸資 | | | | | |
| 投信 | | | | | |
| 自營商 | | | | | |
| 三大法人合計 | | | | | |

判讀原則：

- 夜盤多空淨交易量為正：代表夜盤交易面偏多
- 夜盤多空淨交易量為負：代表夜盤交易面偏空
- 只能描述夜盤交易流向，不能在缺乏 OI 資料時直接認定為新增未平倉
- 必須區分「交易流量」與「未平倉存量」

### 3.4 夜盤核心分析重點

只回答以下兩個核心問題：

1. **夜盤法人交易流向是否顯示隔日可能的方向與風險？**
   - 外資夜盤偏多／偏空
   - 三大法人是否同向或分歧
   - 夜盤法人交易流向是否延續日盤後法人部位趨勢
   - 對隔日日盤開盤方向的可能影響

2. **法人部位變化與夜盤價格漲跌是否一致？**
   - 法人偏多＋夜盤上漲：多方一致
   - 法人偏空＋夜盤下跌：空方一致
   - 法人偏多＋夜盤下跌：多方承接或價格籌碼背離
   - 法人偏空＋夜盤上漲：空方壓力或軋空風險
   - 法人分歧＋價格變動：隔日波動與反轉風險提高

### 3.5 期貨結論

- 日盤後法人淨部位：偏多／偏空／中性

- 夜盤價格：上漲／下跌／震盪
- 法人流向與價格：一致／背離
- 隔日日盤可能方向
- 主要風險與失效條件
