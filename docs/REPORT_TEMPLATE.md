## 0. 執行總則與資料品質 Gate

1. 每次執行必須完成五大模組：現貨、重要市場、期貨、選擇權、綜合總結。
2. 中途即使發生 API 錯誤、來源失效、格式錯誤、逾時或欄位缺失，也不得停止；必須繼續執行並產出 Markdown 報告。
3. 不可取得的資料標示 `N/A`、`未取得`、`來源錯誤` 或 `待補`；不得默認為 0、不得自行捏造或補值。
4. 日盤、夜盤、現貨、期貨、近月選擇權、當週選擇權不得混用。
5. 每一項結論須區分：`官方原始數據`、`計算結果`、`技術分析推論`、`情境假設`。
6. 報告最後必須包含資料品質與錯誤紀錄、Fallback 紀錄、完成度檢查。
