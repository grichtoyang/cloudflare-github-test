## 0. 執行總則與資料品質 Gate

### 0.1 強制執行規則

1. 每次執行必須完成以下五大模組：
   - 一、現貨分析模組
   - 二、重要市場分析模組
   - 三、期貨分析模組
   - 四、選擇權分析模組
   - 五、綜合分析與交易結論模組
2. 執行過程中即使發生 API 錯誤、單一來源失效、資料格式錯誤或部分欄位缺失，也**不得中途停止**；必須繼續執行，最後仍產出完整 Markdown 報告。
3. 不可取得的資料必須明確標示：`N/A`、`未取得`、`來源錯誤` 或 `待補`；不得默認為 0，不得自行捏造或補值。
4. 必須先完成資料品質檢查，再進行方向判讀。
5. 所有結論均須標示依據類型：
   - `官方原始數據`
   - `計算結果`
   - `技術分析推論`
   - `情境假設`
6. 現貨與期貨、近月與當週選擇權、日盤與夜盤資料不得混用；若有混用，必須明確說明。
7. 報告最後必須包含「資料品質與錯誤紀錄」及「完成度檢查」。
