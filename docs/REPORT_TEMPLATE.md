# 每日盤前分析 V1.0 — Markdown 報告模板

> **文件狀態：V1.0 擴充完整定案候選版**  
> 本文件直接覆寫既有 `docs/REPORT_TEMPLATE.md`，不升版、不另建 V1.1。  
> 報告固定包含五大模組：現貨、重要市場、期貨、選擇權、綜合總結。

## 0. 執行與資料品質規則

1. 不得因單一 API、資料源或模組錯誤而提前停止。
2. 即使資料不完整，也必須產出完整 Markdown 報告，並標註 `Unavailable`、`Fallback` 或 `Partial`。
3. 不得捏造數據；所有數值須附資料日期、來源與計算說明。
4. 第五模組只整合前四模組結果，不重新抓取相同資料。
5. 報告最後必須列出成功項目、失敗項目、Fallback 狀態與整體完成度。

## 3.3 夜盤分析：法人佈局與價格反應

> 夜盤只保留三個核心：**A. 日盤後法人未平倉基準、B. 夜盤交易期間法人新增交易流向、C. 夜盤價格漲跌與成交量。** 不擴充成另一套完整技術分析。

### A. 每日日盤後法人未平倉

以日盤結束後公布的資料作為夜盤開始前的基準：

- 外資及陸資淨未平倉
- 投信淨未平倉
- 自營商淨未平倉
- 三大法人合計淨未平倉
- 與前一交易日比較的增減

### B. 夜盤交易期間法人新增資訊

- 夜盤法人交易口數／交易金額
- 夜盤多單交易量、空單交易量及多空淨交易量
- 外資、投信、自營商分項流向
- 夜盤法人流向是否延續日盤後法人部位趨勢
- 三大法人是否同向或分歧

**資料限制必須明確揭露：**

- 若 TAIFEX 公開資料只提供夜盤交易量、交易金額或多空淨交易量，不得宣稱為「夜盤盤中即時未平倉」。
- 「日盤後法人未平倉」是部位存量；「夜盤法人多空交易量」是新增交易流量，兩者不可混用。
- 只有取得可驗證的盤中法人 OI 資料，才可使用「夜盤即時未平倉變化」。

| 法人 | 夜盤多單交易量 | 夜盤空單交易量 | 夜盤多空淨交易量 | 與日盤後基準關係 | 趨勢判斷 |

### 夜盤核心分析問題

1. **夜盤法人佈局對隔日日盤可能方向與風險的影響**
   - 日盤後法人淨部位偏多／偏空／中性
   - 夜盤法人交易流向偏多／偏空／分歧／資料不足
   - 外資夜盤流向是否延續日盤後部位
   - 法人流向對隔日日盤方向的支持程度

2. **法人流向與夜盤價格漲跌是否一致**

| 法人流向 | 夜盤價格 | 判斷 |
|---|---|---|
| 法人偏多 | 夜盤上漲 | 多方一致，方向支持度較高 |
| 法人偏空 | 夜盤下跌 | 空方一致，方向支持度較高 |
| 法人偏多 | 夜盤下跌 | 多方承接、價格背離或多方未主導 |
| 法人偏空 | 夜盤上漲 | 空方壓力、軋空或價格背離風險 |
| 法人分歧 | 價格大幅變動 | 隔日波動與反轉風險提高 |

## 4.2 日盤與夜盤資料規則

- 選擇權 OI 以日盤結束後公布資料為準。

- 夜盤 Call／Put 交易流量不得直接等同夜盤新增 OI。
- 避免將夜盤新增交易資訊與既有盤前 OI 分析重複。

## 4.3 選擇權關鍵位

- Call Wall
- Put Wall

- 期貨與選擇權是否同向或背離
